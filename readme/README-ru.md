## ✨ Функции

### 🔌 Поддержка нескольких протоколов прокси
- **HTTP** - Традиционный HTTP-прокси
- **HTTPS** - Безопасный HTTPS-прокси
- **SOCKS5** - SOCKS5-прокси с поддержкой TCP/UDP
- **SOCKS4** - Совместимость со старым SOCKS4-прокси

### 🔄 Три режима прокси

| Режим | Описание |
|-------|----------|
| **Отключить** | Отключить прокси, использовать системное подключение по умолчанию |
| **Вручную** | Вручную выбрать прокси из списка |
| **Автоматически** | Автоматически выбирать подходящий прокси на основе правил URL (режим PAC) |

| Режим отключения | Ручной режим | Автоматический режим |

### 📋 Гибкая настройка правил URL

- **Адреса без прокси** (`bypass_urls`): Домены/IP для прямого подключения
- **Адреса с прокси** (`include_urls`): Домены, требующие прокси-доступ
- Поддержка подстановочного знака `*` и сопоставления доменов
- Подходит для сценариев, где разные сайты используют разные прокси

### 🔐 Поддержка аутентификации прокси

- Аутентификация по имени пользователя/паролю
- Автоматическая обработка запросов аутентификации прокси-сервера
- Безопасное хранение учетных данных

### 🧪 Функции тестирования прокси

- **Тест подключения**: Проверить доступность прокси
- **Измерение задержки**: Тестировать время ответа прокси
- **Пакетное тестирование**: Тестировать все прокси одним кликом
- **Цветовые индикаторы**: Зеленый(<500ms) / Оранжевый(≥500ms) / Красный(Ошибка)

### 🌙 Режимы темы

- **Светлая тема**: Для дневного использования
- **Темная тема**: Для ночного использования
- **Автоматическое переключение**: Автоматически переключать тему по времени

## 🚀 Быстрый старт

### Установка расширения

1. Откройте Chrome и перейдите по адресу `chrome://extensions/`
2. Включите **"Режим разработчика"** в правом верхнем углу
3. Нажмите **"Загрузить распакованное расширение"**
4. Выберите папку `ProxyAssistant/src` .

### Добавление прокси

1. Нажмите на значок расширения, чтобы открыть всплывающее окно
2. Нажмите кнопку **"Настройки"**, чтобы открыть страницу настроек
3. Нажмите кнопку **"Добавить"**, чтобы добавить новый прокси
4. Заполните информацию о прокси:
   - Имя прокси
   - Тип протокола (HTTP/HTTPS/SOCKS5)
   - Адрес прокси (IP или домен)
   - Номер порта
   - (Опционально) Имя пользователя и пароль
5. Нажмите кнопку **"Сохранить"**

### Использование прокси

**Ручной режим**:
1. Выберите режим **"Вручную"** во всплывающем окне
2. Выберите прокси из списка
3. Статус "Подключено" означает, что прокси активен

**Автоматический режим**:
1. Выберите режим **"Автоматически"** во всплывающем окне
2. Настройте правила URL для каждого прокси на странице настроек
3. Прокси автоматически выбираются в зависимости от посещаемого сайта

## 📖 Подробная документация

### Синтаксис правил URL

Поддерживаются следующие правила сопоставления:

```
# Точное совпадение
google.com

# Совпадение поддомена
.google.com
www.google.com

# Совпадение с подстановочным знаком
*.google.com
*.twitter.com

# IP-адрес
192.168.1.1
10.0.0.0/8
```

### Автоматический режим с PAC-скриптом

Автоматический режим использует PAC (Proxy Auto-Config) скрипты:
- Автоматически выбирает прокси на основе текущего URL
- Поддерживает политику отката (прямое подключение или отказ)
- Автоматически восстанавливает последнюю конфигурацию при запуске браузера

### Горячие клавиши

| Действие | Метод |
|----------|-------|
| Развернуть/свернуть карточку прокси | Клик по заголовку карточки |
| Развернуть/свернуть все карточки | Клик по кнопке "Развернуть все" |
| Переупорядочить прокси перетаскиванием | Перетащить ручку на заголовке карточки |
| Показать/скрыть пароль | Клик по значку глаза в поле пароля |
| Тестировать отдельный прокси | Клик по кнопке "Тест" |
| Тестировать все прокси | Клик по кнопке "Тест всех" |

### Импорт/экспорт конфигурации

1. **Экспорт конфигурации**: Нажмите "Экспорт" для скачивания JSON-файла
2. **Импорт конфигурации**: Нажмите "Импорт" и выберите JSON-файл для восстановления

Конфигурация включает:
- Всю информацию о прокси
- Настройки темы
- Настройки синхронизации

## 🔧 Техническая архитектура

### Manifest V3

- Использует спецификацию Chrome Extension Manifest V3
- Service Worker заменяет фоновые страницы
- Более безопасная и эффективная архитектура

### Основные модули

1. **service-worker.js**:
   - Управление конфигурацией прокси
   - Генерация PAC-скрипта
   - Обработка аутентификации
   - Логика тестирования прокси

2. **popup.js**:
   - Взаимодействие с интерфейсом всплывающего окна
   - Отображение статуса прокси
   - Быстрое переключение прокси

3. **main.js**:
   - Логика страницы настроек
   - Управление прокси (CRUD)
   - Перетаскивание и сортировка
   - Импорт/Экспорт

4. **i18n.js**:
   - Многоязычная поддержка
   - Переключение языка в реальном времени

### Хранение данных

- `chrome.storage.local`: Локальное хранилище
- `chrome.storage.sync`: Облачное хранилище синхронизации
- Автоматическая обработка квоты хранилища

## 📝 Сценарии использования

## ⚠️ Важные примечания

1. **Описание разрешений**: Расширение требует следующие разрешения:
   - `proxy`: Управление настройками прокси
   - `storage`: Хранение конфигураций
   - `webRequest`: Обработка запросов аутентификации
   - `<all_urls>`: Доступ ко всем URL веб-сайтов

2. **Конфликты с другими расширениями**: При конфликтах прокси отключите другие расширения прокси

3. **Безопасность**: Учетные данные хранятся локально в браузере, пожалуйста, обеспечьте безопасность вашего устройства

4. **Требования к сети**: Убедитесь, что прокси-сервер доступен
