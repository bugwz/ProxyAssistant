# 1.7.0 Release Notes

## ✨ 特性
- 新增代理颜色标签，支持预设颜色和严格的 `#RRGGBB` 手动输入，并在主界面与 Popup 中展示

## 🐛 问题修复
- 修复 Popup 场景切换时的状态同步问题，覆盖空手动场景、自动规则匹配和手动代理选择恢复
- 修复代理应用结果的异步处理，避免应用失败时提前更新选中状态
- 修复自动模式切换场景后 PAC 未及时刷新的问题
- 修复在 Popup 中新增或移除绕过规则后配置未持久化的问题
- 修复主界面代理与场景刷新流程，支持切换失败回滚并保持展开状态和数量同步
- 加固 PAC 与规则处理，完善输入转义、IPv4 校验、密码编码、错误消息和监听器管理
- 统一主界面与 Popup 的操作图标及相关界面文案

## 📋 其他
- 新增 GitHub CI 工作流及配套文档
- 整理项目文档目录并补充十种语言的扩展说明
- 统一多种开发工具的代理配置
