# 1.8.2 Release Notes

## ✨ 特性
- 新增手动构建测试安装包的工作流，便于验证指定版本的 Chrome 和 Firefox 扩展

## 🐛 问题修复
- 修复 Chrome 自动模式订阅恢复、手动模式共享绕过订阅及订阅刷新后规则未及时生效的问题
- 统一弹窗与后台的规则匹配逻辑，修正 AutoProxy 域名边界、旧版订阅域名范围、通配符、正则及网段匹配行为
- 修复 PAC 订阅提取边界与资源限制处理，保留解析失败时的有效缓存，避免异常规则影响代理行为
- 修复订阅并发刷新、过期响应及缓存写入竞争问题，避免刷新覆盖尚未保存的表单内容
- 修复配置同步拉取与旧版导入时订阅丢失、缓存误复用的问题，并优化原生同步的分片大小计算与并发上传隔离
- 修复代理操作与连接测试之间的状态竞争，确保测试使用独立表单参数并在结束后恢复代理状态
- 修复代理认证信息未按端点隔离、协议转换不一致及 Firefox 代理失败回退策略的问题
- 修复禁用代理失败时状态丢失、删除情景模式时切换未完成及实体标识可能冲突的问题
- 修复绕过规则保存前校验及编辑期间代理规则校验，完善自定义下拉框的键盘操作
- 修复 Firefox 版本查询超时清理与成功结果保留，并修复直接加载源码时后台服务注册失败的问题
- 补齐并统一多语言界面文案

## 📋 其他
- 更新多语言文档截图及资源引用
- 将持续集成与发布工作流迁移至 Node.js 24，并补充相关回归测试
