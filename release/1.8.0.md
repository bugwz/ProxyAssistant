# 1.8.0 Release Notes

## ✨ 特性
- 新增自动化场景切换，可根据访问条件自动选择代理方案
- 重构代理、配置与订阅管理流程，丰富订阅选择信息，并在页面标题中直观展示代理颜色标识
- 支持多个云同步服务独立配置与运行，完善同步设置和诊断能力
- 新增可自定义的界面主题，全面升级设置导航、运行状态工作区与关于页面
- 增强运行日志操作与诊断信息，便于查看、筛选和处理运行记录

## 🐛 问题修复
- 修复 Firefox 特殊地址处理与 PAC 通配符规则生成问题，并兼容 SwitchyOmega IP 通配符
- 修复订阅刷新覆盖本地编辑、过期订阅闹钟未清理以及代理认证前测试校验不完整的问题
- 修复代理模式切换后弹窗状态不同步、导航状态闪烁和配置文件显示不稳定的问题
- 修复原生同步失败时备份丢失、远程数据连接受限及自定义主题底部控件显示异常的问题
- 修复代理删除预览转义、Chrome 发布包密钥保留和系统元数据混入构建产物等安全与打包问题

## 📋 其他
- 拆分主页面样式并完善测试覆盖，提升界面模块的维护性与发布包验证能力
- 简化配置导出文件名，统一主页面时间显示和本地化提交、发布提示
