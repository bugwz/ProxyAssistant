# 1.8.1 Release Notes

## ✨ 特性
- 统一优化暗色主题的色彩与交互状态，并为代理和订阅列表新增本地化空状态视觉

## 🐛 问题修复
- 优化 Firefox 代理规则匹配器和 Chrome PAC 域名查找逻辑，限制不安全正则与过量规则，提升匹配性能和安全性
- 为订阅下载、解析与后台刷新增加超时、大小、规则数量和并发限制，避免异常资源占用与重复调度
- 为 Gist 手动及定时同步增加超时和任务合并机制，防止请求长时间占用或重复执行
- 修复代理拖拽结束后的自动滚动、动画帧和全局监听器未完全清理造成的资源泄漏
- 统一订阅删除确认对话框的主题、本地化和无障碍交互，并保留自定义下拉框与折叠卡片的圆角边框
- 改善大屏幕与 4K 分辨率下的主页布局，修正暗色主题中手动模式指示色，并补充 Edge 浏览器支持说明

## 📋 其他
- 重写并统一十种语言的项目文档，更新 Chrome、Firefox 和 Edge 安装、权限与当前功能说明
- 补充代理规则性能、订阅与同步资源限制、拖拽清理、样式和对话框无障碍性的回归测试
